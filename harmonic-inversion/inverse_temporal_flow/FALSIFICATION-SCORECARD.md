# Falsification Scorecard — The Chronon / κ Framework

*The capstone. Every quantitative claim the framework makes, in one place: its value, the
measured comparison, the current verdict, and **exactly what observation or computation would
kill it**. Tiered by how the adversarial audit (run on all 56 notes) classified it. Every entry
is reproduced by a script in `verify/`; every "demoted" or "negative" entry records what an
honest re-derivation found. This is the honest scorecard, not a brochure.*

**One-line summary.** The framework is a theory of **dimensionless structure** — a single boost
worldline whose ratios, angles, and combs are real and parameter-free — that **cannot manufacture
a dimensionful scale and is not a tensor theory of spacetime**. Both of those limits are *proven*,
not assumed.

## How to read this

- **φ = (1+√5)/2 = 1.6180…, lnφ = 0.4812…, 1/φ = 0.6180…** are the only constants.
- **Tier 1** — parameter-free, survived every audit. A genuine prediction.
- **Tier 2** — honest bracket: right ballpark, but φ cancels against an external input, or the
  residual is unexplained. Not a clean win.
- **Tier 3** — audit-demoted: looked like a win, but is a coincidence, a circular argument, an
  identity, or a category error. Kept visible as discipline.
- **Negative (proven)** — a question that was *closed*, not abandoned, with the missing object named.

## The single most decisive tests

If you could run only a few experiments/computations to make-or-break the framework:

1. **Cosmic jerk $j_0$ to $\sigma\lesssim10^{-3}$** (Roman + DESI + Euclid joint $H(z)$). The one live
   Tier-1 prediction ($j_0=0.9938$ vs ΛCDM's $1$) that data could confirm or kill. Currently $15\times$
   too coarse.
2. **Reactor $\theta_{13}$** — already at $8.53°$ vs the forced $9.43°$ ($+10.6\%$). A factor-2
   tightening of either the measurement or the framework's lepton-tower derivation resolves it.
3. **GW ringdown overtone spacing** — $e^{\pi/2}$ vs GR's near-degenerate cluster. Existing analyses
   already disfavor it; a dedicated search settles it.
4. **DESI dark-energy evolution** — if the evolving-DE signal strengthens, the near-ΛCDM framework is
   falsified; if it weakens to ΛCDM as systematics improve, the framework returns to consistency.
