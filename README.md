# physics-research-dump

Unorganized public dump of Michael C. Jenkins' independent physics research: the κ coupling function, the Matryoshka-Chronon framework, JSC, Jenkursion, COTV, the κ engines and simulators, and the Prism spectral work.

Each top-level folder is a snapshot of a former private repo (latest state only, no history). `skills/` holds the metamer, nesting-doll and chronon-gi research notes.
