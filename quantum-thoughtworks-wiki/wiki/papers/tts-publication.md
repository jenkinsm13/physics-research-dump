# TTS Publication and Preprints

Publication materials for the [[Temporal Shells|Transfinite Temporal Shells]] (TTS) framework. Multiple versions of the publication exist as both standalone LaTeX files and bundled archives.

## Publication Bundle

`tts_publication_bundle.zip` contains:
- The publication LaTeX source
- Experimental CSV data including ablation results (e.g., `Experiment_E__minimal____Ablation_via_inflated__.csv`)

## ResearchGate Preprints

Two versions of the preprint targeting ResearchGate:
- `tts_rg_preprint.zip` -- initial preprint with `su2_shell_toy.py` (SU(2) shell toy model code)
- `tts_rg_preprint_v2.zip` -- updated version (same toy model)

The SU(2) shell toy model demonstrates TTS dynamics on a simple group-theoretic example.

## Loose LaTeX Files

Multiple iterations of `tts_publication.tex` exist as loose files in `raw/SBIR:QT/`:
- `tts_publication.tex`, `tts_publication 2.tex`, `tts_publication 3.tex` -- successive drafts
- `tts_push.tex` -- a "push" version (likely for submission)

Configuration files `tts_publication_pass.json` and `tts_push.json` accompany these, likely containing compilation or submission metadata.
